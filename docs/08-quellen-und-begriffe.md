## Verwendete Begriffe (vereinfacht)

| Begriff | Bedeutung für die Fallstudie |
|---|---|
| BIA | Business Impact Analyse: zeitabhängige Schadensfolgen von Geschäftsprozessausfällen |
| MTPD | Maximale Ausfallzeit eines Prozesses, bevor untragbare Folgen eintreten |
| RTO | Geforderte Zeit vom Ausfall einer Ressource/eines Prozesses bis zur geeigneten Wiederanlauf-/BC-Lösung |
| RTA | Tatsächlich erreichbare bzw. gemessene Wiederanlaufzeit zum Vergleich mit RTO |
| RPO | Maximal zulässiger Datenrückstand/-verlust bei der Wiederaufnahme, ressourcenbezogene Anforderung |
| RPA | Tatsächlicher Datenwiederherstellungsstand/-verlust zum Vergleich mit RPO |
| MBCO / Notbetriebsniveau | Fachlich benötigte Mindestleistungsfähigkeit des fortgeführten Prozesses |
| GFP | Geschäftsfortführungsplan: Prozessdurchführung im Notbetrieb |
| WAP | Wiederanlaufplan: Wiederanlauf benötigter Ressourcen für den Notbetrieb |
| SLA | Vertragliche Leistungsanforderungen, z. B. zur zulässigen monatlichen Nichtverfügbarkeit |
| Tabletop | Durchgespielte Entscheidungsabfolge; kein technischer Leistungsnachweis |

**Achtung RTO:** Die BSI-200-4-Definition bezieht sich im hier herangezogenen Standard auf den **Ausfall** des Prozesses/der Ressource. Sie ist nicht gleichbedeutend mit einer isoliert gemessenen 15-Minuten-Umschaltung oder einem Countdown nur ab Notfallausrufung.
